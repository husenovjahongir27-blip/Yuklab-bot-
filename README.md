2. Kodni Render.com'ga joylash (bepul)

"Background Worker" bepul emas). Shuning uchun bot.py ichiga kichik health-check
server qo'shilgan — bu Render talab qiladigan portni tinglaydi, botning o'ziga
ta'sir qilmaydi.
